## Current default behavior

Wanderful is an iPhone planning aid for typed same-day hiking, trail-running and biking route requests. It can show point-to-point or loop route options with mapped geometry and routing-response distance, estimated duration and elevation when a reviewed backend is configured. The tracked Production backend URL is currently empty, so live backend planning is not locally proved or promised by this draft.

The app’s native Privacy & data and Help & safety screens remain available when the public privacy and support URLs are empty. Public web links appear only after canonical HTTPS destinations pass strict configuration validation.

Suggested troubleshooting copy:

- Enter a specific town, trailhead or landmark. If Wanderful asks for clarification, add a clearer start, destination, distance, duration or route type.
- If planning fails or no route is returned, retry once, review the message, then edit the request. Do not imply that repeated retries guarantee service.
- Microphone and Speech Recognition permission are optional; typed planning remains the fallback when voice permission is denied.
- Saved routes are local. Use Saved to reopen a route or the trash control to remove saved routes.
- GPX export opens Apple’s share sheet. The selected recipient receives route coordinates; Wanderful cleans temporary files after the handoff and on a later launch if needed.
- Trail Profile answers are local and can be edited, reset or deleted from Profile.

## Future or disabled behavior

Accounts, Supabase sync, paywalls/subscriptions, remote AI, research-guided planning, outdoor-evidence lookup, live navigation, offline maps, live weather and verified current trail/POI conditions are disabled, unavailable or unproved for V1. Support copy must not offer troubleshooting or guarantees for those features unless a later selected build activates and proves them.

If a future release creates an account or remote profile, this page must provide the actual in-app and support deletion path, identity-verification method, affected data classes, retry/failure behavior and retention/backups. Local deletion must never be described as remote account deletion.

## Safety and emergency boundary

Wanderful is not emergency support and does not provide live or turn-by-turn navigation. Routes are planning aids, not guarantees of safety, legality, access, current conditions, scenery or water. Users should review the route and check weather, closures, trail conditions, local rules and water availability. In an emergency, users should contact the local emergency service; the owner must localize that advice without inventing a universal number.
